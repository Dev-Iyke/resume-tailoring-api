# Declaration

I designed and implemented the API's core features, including its data models, relationships, endpoints, authentication, resume handling, and AI generation flow. I used the NestJS CLI starter and generated resource structure as a starting point, then adapted the code for this project.

I used ChatGPT/Codex for explanations, troubleshooting, documentation, and writing tests for features I had implemented. I reviewed the assistance and incorporated it into the project; AI tools did not write the API endpoints or core feature implementation.

The project uses NestJS, Prisma, and PostgreSQL, with libraries including class-validator, Passport/JWT, Argon2, Nodemailer, the Groq SDK, and Vitest/Supertest for testing.
